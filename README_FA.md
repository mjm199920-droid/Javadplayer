# جواد پلیر (Javad Player) — پروژه پایه اندروید

## ساخت APK بدون نصب Android Studio روی کامپیوتر

این پروژه فایل GitHub Actions دارد تا APK را روی سرورهای GitHub بسازد.

1. در GitHub یک حساب بسازید یا وارد حساب شوید.
2. یک مخزن جدید (New repository) بسازید؛ نام پیشنهادی `JavadPlayer` و حالت Private یا Public.
3. فایل ZIP پروژه را از حالت فشرده خارج کنید.
4. محتویات پوشه را در مخزن بارگذاری کنید. دقت کنید فایل `.github/workflows/build-apk.yml` هم بارگذاری شود.
5. در صفحه مخزن وارد زبانه **Actions** شوید.
6. از فهرست سمت چپ **Build Javad Player APK** را انتخاب کنید.
7. روی **Run workflow** و سپس دکمه سبز **Run workflow** بزنید.
8. پس از پایان موفق کار (علامت سبز)، صفحه اجرای workflow را باز کنید.
9. پایین صفحه، بخش **Artifacts**، فایل `Javad-Player-debug-APK` را دانلود کنید.
10. ZIP دانلودشده را باز کنید و `app-debug.apk` را روی گوشی نصب کنید. ممکن است لازم باشد به مرورگر یا فایل‌منیجر اجازه نصب برنامه ناشناس بدهید.

اگر به‌جای علامت سبز، علامت قرمز دیدید، یعنی ساخت با خطا متوقف شده است؛ متن خطا در همان صفحه Actions قابل مشاهده است.

## وضعیت واقعی امکانات در نسخه فعلی

این یک پروژه پایه قابل توسعه است، نه نسخه نهایی و تأییدشده محصول.

- پخش فایل انتخاب‌شده با موتور AndroidX Media3: پیاده‌سازی پایه
- پخش پس‌زمینه با MediaSessionService: پیاده‌سازی پایه
- انتخاب چند فایل صوتی از حافظه: پیاده‌سازی پایه
- علاقه‌مندی‌ها: فعلاً موقت و تا بسته‌شدن برنامه نگهداری می‌شوند
- اکولایزر: رابط اولیه مبتنی بر Android Equalizer؛ پشتیبانی به دستگاه وابسته است
- تغییر pitch: کنترل اولیه از طریق PlaybackParameters
- تم روشن/تیره: نمونه اولیه
- انتخاب پوشه: گرفتن مجوز پوشه؛ پیمایش کامل زیرپوشه‌ها هنوز تکمیل نشده
- مرتب‌سازی بر اساس حجم و مدت‌زمان: هنوز تکمیل نشده
- جداسازی صدای خواننده با هوش مصنوعی آفلاین: هنوز پیاده‌سازی نشده؛ دکمه فعلی فقط توضیح می‌دهد
- سازگاری AUX و Bluetooth: از مسیر استاندارد خروجی اندروید؛ باید روی دستگاه‌های واقعی آزمایش شود

## نکته مهم درباره کیفیت صدا

پخش FLAC به‌خودی‌خود به معنی خروجی bit-perfect نیست. اکولایزر، تغییر pitch، میکس سیستم‌عامل، Bluetooth و سخت‌افزار می‌توانند سیگنال خروجی را تغییر دهند. برای شنیدن بدون پردازش باید DSP خاموش باشد. همچنین MP4 ظرف چندرسانه‌ای است و پشتیبانی صوتی آن به کدک داخل فایل بستگی دارد.
